# Reminder Mobile Application

A simple React Native (Expo) reminder app that lets you:

- Add reminders with a title and optional notes
- Mark reminders as completed/incomplete
- Delete reminders
- Persist reminders locally on-device

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the Expo development server:

   ```bash
   npm run start
   ```

3. Open on a simulator/device:
   - Press `i` for iOS simulator
   - Press `a` for Android emulator
   - Scan QR code in Expo Go

## Scripts

- `npm run start` – start Expo
- `npm run android` – run Android
- `npm run ios` – run iOS
- `npm run web` – run web preview
